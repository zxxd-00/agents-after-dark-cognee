# Salis After Dark

**An AI operations agent that builds and tests business automations while you sleep.**
Agents After Dark @ UC Berkeley — Best Use of Cognee track.

During the day, Salis learns your business rules (stored in **Cognee**). At night it:

**Retrieves memory → Builds a workflow (LLM) → Tests it independently → Imports a lesson from another company → Repairs → Retests → Morning report.**

Nothing is scripted: the workflow is generated by a real model, tested by a separate tester against fresh cases the builder never saw, and the report is read from the job records.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # then add your OpenAI key
```

## Run

```bash
streamlit run app.py               # dashboard: seed memory, Run Now, morning report
python worker.py                   # optional: background night-shift worker
python -m pytest tests/            # offline tests (no API key needed)
```

## Demo (2 minutes)

1. Sidebar → **Seed confirmed rule into Cognee** ("match confirmations by shipment ID, not name").
2. Click **Run Now** (same code path as the overnight worker).
3. The morning report shows: the rule Cognee recalled → workflow v1 → independent tests, including a **shared lesson from a second company** (cancelled shipments must not be marked delivered) → if v1 fails, a repaired v2 → retest → **Approve**.

## How it fits together

| File | Role |
|---|---|
| `salis/memory.py` | Cognee memory, one dataset per workspace; provenance kept in Salis's ledger |
| `salis/builder.py` | LLM proposes a workflow as typed JSON (construct + repair) |
| `salis/workflow.py` | Schema validation + deterministic executor (no model at run time) |
| `salis/tester.py` | Independent tester; checks the resulting records, not claims |
| `salis/shared.py` | Sanitized, signed failure-test artifact from workspace B; opt-in, leak and tamper checks |
| `salis/nightshift.py` | The one job pipeline used by Run Now and the worker |
| `salis/store.py` | Durable job store; every step persisted; crash recovery |
| `app.py` | Streamlit dashboard |
